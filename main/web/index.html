NAT

Для наступного клієнта виберіть іншу вільну VPN-адресу /32 у Allowed IPs. Значення Endpoint Allowed IPs залиште з VPN- і LAN-підмережами. На сервері дозвольте пересилання між WireGuard peer.

Як перенести WT32 в іншу підмережу ＋

Мінімум: підключіть WT32 до нової мережі, визначте нову LAN тут, додайте її у Allowed IPs peer WT32 на сервері та в AllowedIPs уже встановлених віддалених клієнтів (якщо вони не використовують 0.0.0.0/0). Якщо firewall обмежує підмережі, дозвольте нову.

Рекомендовано: після перевірки приберіть стару LAN з маршрутів і оновіть Endpoint Allowed IPs у WGDashboard для майбутніх конфігурацій. Ключі, VPN-адреси й endpoint сервера міняти не потрібно.
